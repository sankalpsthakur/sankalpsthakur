# Sankalp Thakur

I build software for industrial operations, energy systems, and auditable data workflows at [Transient Labs](https://transientlabs.ai).

My work spans industrial AI and automation, carbon accounting, and the open-source infrastructure underneath them. I also explore independent proof checking in Rust.

## Projects to explore

- **[Transient Energy](https://github.com/sankalpsthakur/transient-energy-ems)** — an energy-management prototype covering energy balances, opportunities, and measurement and verification. Fictional data, read-only simulation, no device connections. Runs with a static web server.
- **[Carbon](https://github.com/sankalpsthakur/carbon)** — an AI agent and MCP toolkit for Scope 1/2/3 carbon-accounting workflows. The repository includes installation instructions, tests, and deployment security notes.
- **[Kiota](https://github.com/sankalpsthakur/kiota)** — an experimental, independently implemented Lean 4 kernel checker in Rust. The README documents tested snapshots and remaining limitations.
