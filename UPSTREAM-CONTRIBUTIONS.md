# Upstream contributions

The badge counts [merged PRs in public upstream repositories](https://github.com/search?q=is%3Apr+is%3Apublic+author%3Asankalpsthakur+is%3Amerged+-user%3Asankalpsthakur&type=pullrequests), plus credited changes that upstream landed directly before closing the PR. Each PR counts once. Personal and private repositories are excluded.

It updates automatically every six hours. Closed PRs count only when a commit credits my GitHub account, references the PR using a landing convention, and is verified on the upstream default branch. Future matching landings are discovered automatically; there is no hand-maintained list.

[Latest count and evidence](https://gist.github.com/sankalpsthakur/9cded476f436ff505a842e1f9293c4ae) · [Counting code](./scripts/count_upstream.py)

Incomplete or failed scans keep the previous badge. The evidence includes the last successful update time and separate totals for merged PRs and credited landings. This is a historical contribution count; it does not claim every change remains unreverted.
